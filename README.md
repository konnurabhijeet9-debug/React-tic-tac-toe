# React Tic Tac Toe

A simple two-player Tic Tac Toe game built with React.

## Features

- Two-player gameplay (X and O)
- Winner and draw detection
- Winning cell highlighting
- Scoreboard for wins and draws
- Undo the last move
- Reset game and reset scoreboard
- Move history with row and column positions
- Responsive interface

## Technologies

- React
- JavaScript
- HTML
- CSS
- Vite (if used in this project)

## Getting Started

1. Clone the repository.
2. Install dependencies using `npm install`.
3. Start the development server using `npm run dev` (if using Vite).

## How to Play

Player X starts first. Players take turns selecting empty cells. The first player to match three marks horizontally, vertically, or diagonally wins. If all cells are filled without a winner, the game ends in a draw.
